# **Fundamentos de Programación en C**
##*Descripción*

Este repositorio contiene ejemplos y prácticas básicas del lenguaje de programación C, enfocados en comprender la estructura del lenguaje, la lógica de programación y la ejecución de programas.

##*Objetivo*

Desarrollar habilidades en programación utilizando el lenguaje C, comprendiendo su sintaxis, estructuras básicas y su aplicación en la resolución de problemas.

##*Proyección a futuro*

El lenguaje C es fundamental en el desarrollo de software debido a su cercanía con el hardware y su eficiencia. Es ampliamente utilizado en:

- Sistemas operativos
- Desarrollo de software embebido
- Controladores (drivers)
- Programación de bajo nivel
- Bases para otros lenguajes como C++ y Java
