# **Ejercicios de Servicio Social**

##*Introducción*
Este repositorio contiene una serie de ejercicios desarrollados durante la realización del servicio social, con el objetivo de reforzar conocimientos en el uso de herramientas tecnológicas, control de versiones y administración de sistemas.

El propósito principal es documentar y practicar actividades relacionadas con el desarrollo, organización de código y uso de Git, permitiendo mejorar habilidades técnicas aplicadas en un entorno real.

## *Objetivos*

- Aplicar conocimientos adquiridos en la carrera  
- Desarrollar habilidades prácticas en diferentes áreas tecnológicas  
- Aprender el uso de herramientas de desarrollo y administración  
- Mejorar la organización y documentación de proyectos  
- Trabajar con control de versiones mediante Git  


## *Estructura del Proyecto*

El repositorio se encuentra organizado en las siguientes carpetas:

- **BaseDeDatos** → Contiene ejercicios relacionados con bases de datos  
- **Codigo** → Incluye prácticas de desarrollo y programación  
- **Git** → Ejercicios enfocados en el uso de control de versiones  

## *Herramientas utilizadas*

Durante el desarrollo del servicio social se utilizaran las siguientes herramientas:

- Git  
- PowerShell  
- Sistemas gestores de bases de datos  
- Editor de código (Visual Studio Code)  
- Sistema operativo Windows Server  
- Entre otras
---

## *Actividades realizadas*  

- Administración de procesos y servicios del sistema  
- Creación y manipulación de archivos  
- Uso de comandos en PowerShell  
- Gestión de repositorios con Git  
- Desarrollo de ejercicios de programación  
- Organización de información y documentación  

---

## *Control de versiones*  

Se utilizó Git como sistema de control de versiones para:

- Registrar cambios en los archivos  
- Mantener un historial del proyecto  
- Sincronizar el trabajo con un repositorio remoto
